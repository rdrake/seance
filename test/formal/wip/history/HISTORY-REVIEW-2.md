## Remaining/new defects

- **Blocking: NoneOlder is not “next page empty.”** Let snapshot order and eligibility be `<<1,2>>` and `{1,2}`, with returned batch `<<2,1>>`. NoneOlder is true because nothing was omitted, yet BEFORE the client's next anchor 2 returns 1. This is allowed with BatchAgrees off. The predicate ignores batch order and excludes already-returned messages from consideration; both choices hide the original review's counterexample. The empty-S arm also declares exhaustion even with eligible messages remaining. Define the next selector explicitly and test its snapshot eligibility, or name this as an exhaustion abstraction rather than D9's wire meaning (`model/History.tla:118`, `model/History.tla:129`, `model/History.tla:173`, `model/History.tla:196`, `model/History.tla:243`; `../formal-spec/specs-src/extensions/chathistory.md:136`, `../formal-spec/specs-src/extensions/chathistory.md:204`, `../formal-spec/specs-src/extensions/chathistory.md:208`).

- **The identity split leaks into two oracles.** NoLoss correctly uses content; CoverDone still uses raw msgids. CoverLiveInPage likewise compares a content identity directly with wire msgids. Both silently miss their intended events under HS_NewId. Conversely, dedupe, held-overlap detection and NoDupLive should keep comparing msgids: those are identity-based client behavior, not content-based recovery (`model/History.tla:160`, `model/History.tla:192`, `model/History.tla:219`, `model/History.tla:234`, `model/History.tla:249`, `model/History.tla:257`).

- **Selector decoding grants the server an omniscient alias.** `Content(qq.sel)` accepts a minted replay id as the original selector. This is defensible only as an explicit mutant abstraction; it is not opaque msgid lookup and will mask unknown-id handling if carried into v1. ReplayIdStable is also only an id-range check, sufficient for this one minting mutant, not a general original-id/provenance check (`model/History.tla:41`, `model/History.tla:102`, `model/History.tla:232`; `../formal-spec/specs-src/extensions/message-ids.md:41`, `../formal-spec/specs-src/extensions/chathistory.md:126`).
