## Remaining limitations to carry into v1

- **EndTruthful is snapshot-stable, but not an independent semantic oracle.** It reuses the generator's EndOK; HS_FalseEnd tests bypassing that predicate, not whether the predicate means next-query emptiness. Add a separately expressed snapshot next-selector eligibility check and the reversed-batch/empty-with-eligible regression cases. Also qualify exactness: with timestamp anchors and tied times, next eligibility can be empty although Pos is not 1; with minted anchors, opaque lookup is empty although the decoded content is not oldest. Current tagging is conservative in these cases, not falsely affirmative (`model/History.tla:105`, `model/History.tla:106`, `model/History.tla:123`, `model/History.tla:178`, `model/History.tla:248`, `model/mkhist.py:62`).
- **Unknown lookup is implemented, not adequately isolated by these checks.** A nonzero unknown or minted BEFORE id selects nothing; zero remains the timestamp discriminator. LATEST still ignores selectors. Add explicit unknown-selector and minted-continuation checks; separate wildcard, timestamp and msgid selector forms before extending LATEST (`model/History.tla:101`, `model/History.tla:104`, `model/History.tla:176`, `model/mkhist.py:57`, `../formal-spec/specs-src/extensions/chathistory.md:95`).
- **Identity separation otherwise holds.** Recovery, content uniqueness and live-content covers use content; dedupe, held overlap, anchor and NoDupLive use msgids. Time decoding represents message metadata, not selector resolution. Page eligibility and end decode replay content against the snapshot. ReplayIdStable remains only the explicitly admitted range check: it cannot validate arbitrary original-id provenance (`model/History.tla:76`, `model/History.tla:164`, `model/History.tla:188`, `model/History.tla:196`, `model/History.tla:200`, `model/History.tla:224`, `model/History.tla:227`, `model/History.tla:230`, `model/History.tla:234`, `model/History.tla:237`, `model/History.tla:239`, `model/History.tla:243`, `model/History.tla:248`, `model/History.tla:261`).
