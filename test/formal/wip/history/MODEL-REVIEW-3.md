## 2. New code: correctness and exclusions

- **Queue/map/root buffering: correct for generated ordinary responses.** Per-label FIFO emission preserves each response's framing while allowing arbitrary cross-response scheduling. Opening inherits label/history/root; inner end leaves the root buffer intact; root end folds wire order. IDs fit `RefIds` for at most MaxReq answers plus one history replay. No malformed-reference validation is provided or needed for this restricted generator (`model/Delivery.tla:41,151,162-164,191-194,255-258,307-327`; `../formal-spec/specs-src/extensions/batch.md:51-63,100-123`).
- **High: History is not part of that queue.** All three forms append start, replay and end in one step. Client processing/timeouts/close can occur between their consumption, but no ordinary echo, other-session line or second batch start can occupy a wire position between them. Thus a buggy global “some history is open, suppress all echoes” guard is observationally equivalent here to the correct per-reference history guard. None of the listed mutants challenges that bug. Queue history line by line and cover a live echo consumed while history is open (`model/Delivery.tla:220-239,258,283`; `model/list-d3:20-27,51-59`; `DECISIONS.md:130,314-321`; `../formal-spec/specs-src/extensions/batch.md:93-98`).
- **History forms/guard themselves are correct.** Plain, nested LR and directly labeled history have the required membership; history propagates through the map and is saved before Deferred closes the map entries. Recognition uses batch state, not the ghost role. However, `HistLabel` is merely a distinguished constant: no CHATHISTORY request/label lifecycle is modelled, and replay text need not have been sent. This is a useful abstract interface, not a complete request/replay interface (`model/Delivery.tla:35,223-236,258,277,283,310,322`; `DECISIONS.md:361-375`; `../formal-spec/specs-src/extensions/labeled-response.md:55-58`; `../formal-spec/specs-src/extensions/chathistory.md:65,71`).
- **Competing and CloseOn match the decisions.** Both echo/FAIL orders exist; pending-only settlement absorbs the second; close fails remaining copies and clears wire, queues, map and buffers, then disables all actions. Close has no fairness, as intended. Competing 4xx is not generated, but D17's implemented switch explicitly chooses FAIL (`model/Delivery.tla:169-175,267,341-368`; `DECISIONS.md:333-359`).
- **Notice and Modify are only partially exercised.** NOTICE has no generated error, and fallback matches command, target and text correctly. Modified labeled echoes still settle by label. But SLate always uses the original text even with Modify on; the only other modified unlabeled source is self-delivery, and V2Modify disables SelfMsg. Therefore the suite never exercises D20's altered-unlabeled-echo cross-match/no-match cases. Also Wrap permits delivery only before or after the entire response, excluding delivery between its batch delimiters. Add those cases or explicitly document narrower restrictions (`model/Delivery.tla:152-155,174-175,203,247-248,284-285`; `model/V2Modify.cfg:8-18`; `DECISIONS.md:379-391`; `../formal-spec/specs-src/extensions/echo-message.md:21-24`; `../formal-spec/specs-src/extensions/labeled-response.md:60`).
- **Obligations are correct but not independent enough.** Their wire-tail test identifies CRecv in the current action set; excluding close/history and requiring a pending copy prevents false obligations. Deferred correctly selects the first eligible line per label. Neither property requires unlabeled fallback consumption. More seriously, Immediate shares EffLab with the implementation, and Deferred trusts the client's already-built buffer and saved labels/history: wrong association or lost buffering can weaken the oracle itself. Keep these local checks, but add a wire-derived ghost log/association oracle before relying on them as end-to-end consumption evidence (`model/Delivery.tla:255-258,305,322,422-438`; `DECISIONS.md:399-416`; `DESIGN.md:66-69`).
